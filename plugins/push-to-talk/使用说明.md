# Push-to-Talk（按住左 Ctrl 说话）

Qiu_Ai_LZ 插件：任何页面位置按住左 Ctrl 说话，松开自动识别填入聊天框。
零点击、零标签页操作。

## 使用

| 动作 | 效果 |
|------|------|
| 任意位置按住左 Ctrl ≥0.25 秒 | 自动聚焦聊天框并开始录音（右下角红条常驻） |
| 松开左 Ctrl | 停止 → 识别 → 文字进对话框 |
| 轻点一下左 Ctrl | 无效果 |
| 按住期间又按别的键 | 放弃录音判定，组合键（Ctrl+C/V）正常 |
| 录音中 Esc / 切走窗口 | 取消本次 |
| 焦点在其他输入框（搜索/设置） | 不触发，不抢焦点 |

语音后端沿用应用内「语音配置」：配了直连 Whisper 直连，否则走 `/api/voice/transcribe`。

## 安装位置

- 插件本体：`C:\Users\<用户名>\.claude-code-ui\plugins\push-to-talk\`
  （index.js + manifest.json，含 `backgroundOnly: true` 不显示页签）
- 设置 → Plugins 里打开开关即用（PluginAutoBoot 会自动激活已启用的插件）

## 更新 Qiu_Ai_LZ 后的恢复

自动激活补丁写在项目源码里，更新会被覆盖（插件本体不受影响）。
恢复方法——运行本文件夹 `patch/apply-push-to-talk-patch.sh`：

    bash ~/.claude-code-ui/plugins/push-to-talk/patch/apply-push-to-talk-patch.sh [项目根目录]

默认项目根目录是 D:/Claude_Tools/claudecodeui。生产模式跑完再执行 npm run build。

## 迁移到别的电脑/程序副本

1. 把本文件夹整个拷到那台机器的 `~/.claude-code-ui/plugins/push-to-talk/`
2. 在那边的 Qiu_Ai_LZ 项目上运行一次上面的恢复脚本
3. 设置 → Plugins 里启用
