# Qiu_Ai_LZ

一个给 Claude Code CLI 套上图形界面的本地 Web / 桌面应用：聊天对话、消息级回退、回合改动审查、文件浏览与编辑、Git 操作、内置终端、语音操控、手机远程访问，全部在一个界面里完成。完全本地运行，无云端依赖。

基于开源项目 [siteboon/claudecodeui](https://github.com/siteboon/claudecodeui) 深度定制。

---

## 给 AI 助手 / 快速总览

如果你是 AI 助手，正在帮用户部署这个项目，按下面的顺序执行即可。关键事实：

- **技术栈**：前端 React 18 + Vite + Tailwind；后端 Node.js + Express + WebSocket + better-sqlite3；桌面壳 Electron
- **端口**：后端/API/Web 界面 `3001`（生产模式唯一入口）；开发模式前端另占 `5173`
- **启动命令**：`npm install` → `npm run build` → `npm run server`，然后打开 `http://localhost:3001`
- **健康检查**：`curl http://localhost:3001/health` 返回 `{"status":"ok",...,"version":"1.1.0"}`
- **首次打开**：需在页面里注册一个本机账号（仅存本机 SQLite），然后在侧边栏选择一个本地文件夹作为项目
- **硬性前置**：本机已安装并登录 [Claude Code CLI](https://claude.com/claude-code)（终端里运行 `claude` 能进入对话即可），本应用是其图形界面，没有它无法对话

## 让 Claude CLI 走自定义模型（中转/代理）

官方订阅用户无需任何配置。如果你通过中转站或本地代理使用其他模型，编辑 `~/.claude/settings.json`：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://127.0.0.1:15721",
    "ANTHROPIC_API_KEY": "你的中转key",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "claude-sonnet-4-6[1M]"
  }
}
```

界面右上角的模型下拉列表会自动反映 CLI 的可用模型。上下文用量进度条会优先读取模型名里的 `[1M]`/`[200k]` 窗口标记。

# 功能详解

> 下面每个功能都写清「在哪用、怎么用、效果是什么」。

## 聊天对话

- 在输入框打字发送（Enter 发送；设置里可切换为 Ctrl+Enter），模型回复**逐字流式**渲染，支持 Markdown、代码高亮、公式
- 工具调用（读写文件、执行命令等）以卡片形式展示，可以展开看完整参数与输出
- 支持**多智能体**：右上角可切换 Claude Code / OpenAI Codex / Cursor 等不同后端，界面操作完全一致
- 支持图片与文件附件：直接粘贴截图、拖拽文件进输入框
- **打断**：生成过程中输入框会变成红色停止按钮，点击或按 **Esc** 立即停止。效果是彻底的——立刻停止生成、界面不残留任何半截内容、转录中不会"复活"出完整回答、正在等待你审批的工具调用也一并取消；就算 CLI 进程卡死，4 秒后会自动强制关闭，不会出现"停不下来"

## 编辑重发（✎）

- 把鼠标悬停在**你发的消息**上，消息时间戳旁会出现 **✎**
- 点击后原文完整载入底部输入框（进入编辑模式，聊天区顶部有"正在编辑"指示条），改动后回车发送
- 效果：**这条消息之后的全部对话会被截断**，以你修改后的内容重新开始——相当于"收回重说"
- 按 **Esc** 取消编辑并恢复你原来的草稿；仅 Claude 会话提供此功能

## 回退（⟲）——把会话和文件一起拨回去

- 悬停在你发的消息上，时间戳旁的 **⟲**（逆时针箭头）就是回退按钮
- 点击后弹出确认框 → 确认后：
  - 这条消息**及之后的所有对话**从会话中删除
  - **代码/文件恢复到这条消息执行之前的状态**（基于 Claude Code 的 checkpoint 快照；后来新建的文件会被删除）
  - 界面显示统计：丢弃了多少条记录、恢复了多少个文件，完成后自动刷新
- 转录文件在截断前会自动备份（`.bak-rewind-时间戳`），CLI 侧的会话记忆不受影响，随时可以继续对话
- 适用场景：让 agent 改错了东西、方向走偏了、或者想换一种问法从头来过。仅 Claude 会话提供

## 回合文件更改折叠条（N 个文件已更改）

- 每一轮对话结束后，聊天区会出现一条 `› N 个文件已更改 +X -Y` 的折叠条（与官方 Claude Code 一致）
- **点箭头展开**：列出本轮改动的每一个文件及其增删行数
- **点击任意文件**：在右侧代码编辑器中打开该文件的 **diff 对比视图**，逐行审查 agent 到底改了什么
- 数据是真实统计：只计 Edit/Write/MultiEdit/NotebookEdit 等实际落盘的修改（含子代理内的修改），失败的调用不计入
- 生成过程中数字实时更新

## 提问点导航轨

- 聊天区左侧有一条按你的每条提问生成的**密排刻度轨**
- 滚动时当前视角在轨上有波浪跟随动效；**悬停刻度**预览那一轮的问答摘要；**点击**直接跳转到该轮置顶
- 长会话翻找历史时不用再无限滚动

## 上下文用量条

- 输入框上方的进度条实时显示**当前对话占用的上下文窗口比例**
- 读取自模型真实的 token 用量（输入+缓存），而非回合结算的累计值；会话切换不掉零
- 模型名带 `[1M]`/`[200k]` 标记时自动按声明窗口计算；快满时颜色变化，提醒你该开新会话或压缩

## 会话管理：搜索 / 排队 / 后台并行

- **侧栏会话搜索**：跨所有项目的对话内容实时搜索（边打字边出结果），命中条目高亮
- **排队消息**：agent 还在生成时你发的消息会自动排队（可编辑/删除），上一轮结束后自动发出
- **后台并行**：切到别的会话不影响正在生成的会话，每个会话独立显示运行状态；生成完成时桌面通知 + 提示音
- 左侧导航轨之外，侧栏也按项目分组管理会话，支持归档与删除

## 文件树与代码编辑器

- 左侧文件树展示项目全部文件（尊重 .gitignore），点击在右侧 **CodeMirror 6 编辑器**打开：语法高亮、行号、代码折叠、minimap
- 支持新建/重命名/删除文件与文件夹、上传文件
- **diff 视图**：从聊天区的文件更改折叠条或工具卡片点开的文件，会以对比模式展示修改前后差异
- Ctrl+S 保存；有未保存修改时关闭编辑器会先确认，防止误丢改动

## Git 面板

- 状态 / 暂存 / 提交 / 分支创建与切换 / 提交历史与 diff / 远端 Fetch / Pull / Push / 发布新分支
- 支持中文分支名；操作失败时**具体原因直接显示在面板上**（不再静默吞错）
- 面板顶部还有 AI 生成 commit message 的快捷入口

## 内置终端

- node-pty 驱动的真实 shell（Windows 为 PowerShell），多标签，可同开多个
- 与聊天共享项目目录；会话级终端在重开应用后可恢复

## MCP 管理

- 可视化查看/编辑各 Provider 的 MCP 服务器配置（`~/.claude.json` 的项目级与全局级）
- 改完即时生效，不需要手动编辑 JSON

## 手机访问

- **设置 → 手机访问** 中开启：局域网模式扫局域网地址，或公网模式一键启动 Cloudflare 隧道（cloudflared 自动下载并校验完整性）
- 手机浏览器打开地址 + **6 位 PIN 配对**（30 分钟内 5 次尝试限制 + 连续失败锁定），即为完整操作界面：聊天、文件、Git、终端全部可用
- 支持 PWA 安装到主屏；同屏通知可推送到手机
- 支持桌面通知 + 提示音；PWA 安装后可推送到手机
- 手机上语音输入同样可用：聊天输入框旁的麦克风按钮点按录音，松开识别

## 通知

- 会话生成完成、等待你审批工具时：桌面通知 + 提示音；PWA 安装后可推送到手机
- 可按事件类型在 设置 → 通知 中分别开关

## 界面

- 深色/浅色主题、简体中文等多语言、命令面板（Ctrl+K 快速跳转与执行）

# 语音与按住说话（配置指南）

语音功能分三块：**语音输入（STT）**、**语音回复（TTS）**、**按住说话（Push-to-Talk）**。全部依赖一个 **OpenAI 兼容的语音接口**——不配置的话语音功能不可用，其余功能不受任何影响。

## 第一步：准备一个语音接口

任何 OpenAI 兼容接口都可以（提供 `/audio/transcriptions` 和 `/audio/speech` 端点）。**推荐硅基流动 SiliconFlow**，有免费额度，国内直连：

1. 打开 [https://cloud.siliconflow.cn](https://cloud.siliconflow.cn) 注册/登录（手机号即可，送免费额度）
2. 左侧菜单 → **API 密钥** → **新建 API 密钥** → 复制（`sk-` 开头，只显示一次）

## 第二步：在应用里填写配置

打开 **设置 → 语音**：

| 配置项 | 填写值 | 说明 |
|---|---|---|
| Base URL | `https://api.siliconflow.cn/v1` | 留空则走本机代理（按下面的 Key 同源转发） |
| API Key | 上一步复制的 `sk-…` | 只存本机 localStorage |
| STT 模型 | 见下表 | 语音识别 |
| TTS 模型 | 见下表（可留空） | 语音回复，留空则不朗读 |

### 模型推荐（硅基流动实测）

| 用途 | 模型名 | 说明 |
|---|---|---|
| 语音识别 STT（免费） | `FunAudioLLM/SenseVoiceSmall` | 免费但高峰期拥挤：2026-09-10 实测单次成功要 ~37s 且常挂起；应用内置瞬时错误重试 2 次 + 单次 45s 超时，识别中可点击浮条或按 Esc 取消 |
| 语音识别 STT（付费，快而稳） | `Qwen/Qwen3-ASR-1.7B` | 2026-09-10 实测 0.5s 响应、中文识别准确；官方价 ¥0.00022/秒（≈¥0.013/分钟，说一句话约 1 厘~2 厘钱）——免费模型抽风时首选 |
| 语音识别 STT（付费） | `XingChenAGI/XingChenASR-V3.2` | 实测 0.7s 响应、成功率高，按量计费 |
| 语音回复 TTS | `FunAudioLLM/CosyVoice2-0.5B` | 可选音色，用于朗读 AI 回复 |

更多模型在 [硅基流动模型广场](https://cloud.siliconflow.cn/models)（筛选「音频」分类）查看。不限于硅基流动——其他服务商只要 BaseURL + Key + 模型名三件套齐全即可（如 OpenAI 官方 `whisper-1`）。

**验证配置**：配置保存后，输入框旁的麦克风按钮变为可用；点一下开始录音，再说一句话，松开后文字会自动填入输入框。

## 第三步：按住说话（Push-to-Talk，日常最顺手）

内置的按住说话功能，**默认开启**，配好语音接口后立即可用：

| 操作 | 效果 |
|---|---|
| **按住左 Alt 说话** | 按住约 0.25 秒后开始录音（右下角有红色指示条），**松开**自动识别并把文字填入输入框 |
| 输入框没聚焦时按 Alt | 先自动唤起并聚焦聊天输入框，再开始录音——任何时候喊话都行 |
| 说话过程中按 **Esc** | 取消本次录音，不识别 |
| 按住期间按了别的键（Alt+Tab 等） | 自动放弃本次，不会误录 |
| 快速轻点左 Alt | 无任何效果（右 Alt 完全不受影响） |

- 识别结果**追加在输入框**，你可以继续修改后再发送；配合消息发送键直接语音下一句
- **换键位 / 关闭**：设置 → 语音 → 「按住说话」区块，可在 左 Alt（全局）/ 空格长按（输入框内）/ Ctrl+M（全局）之间切换，或整体关闭
- 拼音打字选字不受影响（输入法组字期间自动忽略）；空格键位模式下轻点仍是普通空格

### 常见语音问题

| 现象 | 处理 |
|---|---|
| 麦克风按钮灰色/按住没反应 | 浏览器首次使用需允许麦克风权限；确认系统麦克风可用 |
| 识别偶发失败 | 免费模型高峰期过载，应用会自动重试 10 次；仍失败可换付费模型 |
| 识别出来是空的 | 录音太短（<1 秒）或环境噪音，靠近麦克风再说一次 |
| 想换快捷键 | 设置 → 语音 → 按住说话 → 触发键位 |

# 其他

## 插件（第三方扩展）

回退与按住说话已内置为原生功能，无需安装任何插件。项目同时保留了一套通用插件系统供扩展：

- **设置 → 插件** 中粘贴 Git 仓库地址即可安装
- 插件 = `manifest.json` + 前端入口（可带 Node 后端文件），支持 tab 挂载点和后台模块（`backgroundOnly`，如全局快捷键类）
- 安装位置：`~/.claude-code-ui/plugins/`（桌面壳/`.env` 的 `QIU_PLUGINS_DIR` 可改）
- 换图标：替换 `desktop/assets/logo-windows.ico` 后执行 `node scripts/regenerate-icons.mjs`，全套 27 个图标（PWA/favicon/logo/icns）一键重生成

## 故障排查

| 现象 | 处理 |
|---|---|
| 打开页面空白 | 执行 `npm run build` 后刷新；桌面壳会自动做这一步 |
| 桌面壳卡在「构建中」 | 源码有更新时首次启动会自动重建，约 1 分钟；构建不清空旧产物，完成后自动进入 |
| 无法对话 / 提示 CLI 未安装 | 终端运行 `claude` 确认 CLI 可用并已登录；不在 PATH 时在 `.env` 设 `CLAUDE_CLI_PATH` |
| 会话报错后无法继续 | 对任意历史消息点 ⟲ 回退即可重建会话，无需手动删转录文件 |
| 按住 Alt 没反应 | 确认已配置语音接口且「按住说话」开关开启；浏览器需已授权麦克风 |
| 回退按钮没出现 | 回退/编辑仅 Claude 会话提供（其他 provider 转录格式不同） |
| 上下文进度条不动 | 模型名加 `[1M]`/`[200k]` 窗口标记，或在 `.env` 设 `CONTEXT_WINDOW` |

- **打断七道加固** — ESC/停止立即生效：停止生成、界面无残留、转录不复活、待审批工具一并取消、CLI 卡死 4 秒自动强杀
- **安全加固** — 修复任务管理模块的路径穿越（任意文件读/写）、手机端 PIN 爆破绕过、克隆日志 token 泄漏、编辑器并发竞态与错误缓冲可保存等 20 项
